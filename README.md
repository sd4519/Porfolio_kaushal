# Kaushal portfolio

From this folder, run:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite (normally http://localhost:5173).
Stop the server with Ctrl+C. Additional Vite options can be passed with `npm run dev -- --port 5174`.

The app lives in `homepage-wireframe/`. The visual source of truth is [docs/design.md](docs/design.md).
Use `npm run build` for a production build and `npm run preview` to preview that build.
